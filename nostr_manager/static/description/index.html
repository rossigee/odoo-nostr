🔐 Nostr Key Management

Secure management of Nostr public and private keys with vault integration. Acts as both a Nostr address book (for collecting npubs) and a secure key manager (for managing nsecs).

✨ Features

🧙‍♂️ 2-Step Key Generation Wizard

Clean, secure wizard for generating new Nostr key pairs:

  • Step 1: Enter key name and optional partner association
  • Step 2: View and copy generated nsec/npub (one-time display only)

🗂️ Dual Purpose: Address Book + Key Manager

Visual distinction in list views:

  • Address Book Mode: Store public keys (npubs) only for contact management
  • Key Manager Mode: Full key pairs with private keys securely stored in vault
  • Color Coding: Blue for public-only, green for full key pairs

🔒 Vault Integration

Private keys are never stored in the database:

  • Secure storage via vault_connector module
  • UUID-based vault key references
  • Vault connectivity checks before operations

🏷️ Partner Association

Optional partner linking with dedicated tab:

  • Associate keys with business partners
  • Partner form shows key count and active key
  • Quick key generation from partner view

💬 Activity Tracking

Full chatter integration:

  • Field change tracking (name, partner, notes)
  • Message history and comments
  • File attachments (QR codes, backups, etc.)
  • Activity scheduling (key rotation reminders)

📋 Copy-Friendly Interface

Easy key sharing and management:

  • Copy buttons next to all key fields
  • Clean key display with proper formatting
  • Public keys safely displayed for sharing

🚀 Usage

Generate New Key

  1. Go to Administration > Nostr Key Management > Generate New Key
  2. Enter key name and optional partner
  3. Click "Generate Keys"
  4. Copy and securely save your nsec private key
  5. Share your npub public key as needed

Add Public Key Only

  1. Go to Administration > Nostr Key Management > Nostr Keys
  2. Click "New" to create a record
  3. Enter name, partner (optional), and paste npub
  4. Save - will be marked as "Public Key Only"

⚠️ Security Notice

Private keys (nsec) are shown only once during generation. Make sure to copy and save them securely offline. The application will never display them again for security reasons.

🔧 Configuration

Requirements

  • vault_connector module installed and configured
  • HashiCorp Vault server accessible
  • Proper vault environment variables set

Dependencies

  • base - Core Odoo functionality
  • mail - Chatter and activity tracking
  • vault_connector - Secure private key storage

📝 Technical Notes

Access Control: Users can create, read, and modify keys. Only system administrators can delete keys from the system.
